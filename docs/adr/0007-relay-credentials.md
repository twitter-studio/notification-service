# ADR-0007: 中継の資格情報の入れ替えと取り消し

Status: Accepted / 2026-11-04

## 背景

設計書 v1.1 の §3 と §4 は、利用者の Worker が使う中継の資格情報 (relay secret) を、1 回だけ見せ、利用者が入れ替えと取り消しをできるようにすることを求めている。入れ替えには、アカウントのセッションに加えて、新しい証明 (fresh proof) が要る。最初の資格情報は、登録のときに作る (ADR-0006)。

## 決定

- **形と置き方**: ADR-0006 のとおり。`tsr_` と 32 バイトの乱数。DB には SHA-256 だけを置き、平文は作った応答でだけ返す。
- **確かめ** (`requireRelayCredential`): `Authorization: Bearer tsr_…` のハッシュで、取り消しておらず、期限内で、アカウントが有効な資格情報を引く。送り先のアカウントは、これだけで決める (ADR-0001)。
  - ハッシュは DB の索引で引く。引く時間からハッシュの一部が分かっても、256 ビットの乱数の元の値は探せないので、時間をそろえる比べ方はしない。
  - 使った時刻 (`last_used_at`) を、1 時間に 1 回まで書く。利用者が、使っていない資格情報を見つけられるようにする。
  - 中継の入口の回数の制限は、API-003 で付ける。
  - インストールを取り消しても、資格情報は使える。取り消したインストールの端末の行は消してあるので、送っても届かない。
- **入れ替え** (`POST /v1/relay-credentials/rotate`): アカウントのセッションと、端末の鍵の署名で行う (201)。
  - 署名する文は `twitter-studio/relay-credential/v1\n<チャレンジ>\n<インストールの ID>`。チャレンジは用途 `relay_credential` で出したもの。インストールはセッションのもの。
  - 1 つのバッチで、チャレンジを使ったものとして記録し、アカウントの使える資格情報をすべて取り消し、新しいものを置く。バッチの途中でインストールやアカウントが止まっても、資格情報を作らない。続けて入れ替えても、使えるのは最後のものだけ。
  - 応答で、新しい資格情報の ID と秘密を返す。秘密を返すのは、この応答だけ。
  - インストールごとに、1 分に 5 回まで (`INSTALLATION_RATE_LIMITER`。セッションの作り直しとは別に数える)。
- **取り消し** (`DELETE /v1/relay-credentials/{id}`): アカウントのセッションで行う (204)。
  - ほかのアカウントのもの、取り消し済み、ないものは、区別せずに 404。
  - 取り消すと、使える資格情報がなくなり、中継は 401 になる。使い直すには、入れ替えで新しいものを作る。
- **期限**: 既定では付けない。資格情報は利用者の Worker に置かれ、期限で切れると、利用者が気づかないまま通知が止まるため。表には期限の列があり、確かめでは期限を見る。期限を付けるときは、切れる前に知らせる仕組みと一緒に決める。
- 利用者の Worker は、中継の 401 をやり直さない。資格情報を入れ替えたら、利用者が Worker の秘密 (`RELAY_TOKEN`) を新しい値にする (USER-001)。

## 採らなかった案

- **セッションだけで入れ替える**: 漏れたセッション (1 時間) で、新しい秘密を作れてしまう。取り消しは能力を失うだけなので、セッションだけでよい。
- **入れ替えた後も、前の資格情報を少しのあいだ使えるようにする**: 漏れた資格情報を入れ替えて止めたいときに、すぐ止まらない。設計書も、入れ替えで前のものを取り消すとしている。
- **サーバーの鍵の HMAC (pepper) で置く**: 32 バイトの乱数は、ハッシュから総当たりで探せないので、鍵の管理を増やす意味がない (ADR-0006)。
- **資格情報の一覧を返す入口**: v1 のアカウントは使える資格情報を 1 つだけ持ち、ID は登録と入れ替えの応答で返す。要るようになったら足す。

## 影響

- アプリ (IOS-001) は、設定に入れ替えと取り消しを置き、入れ替えたときは秘密を 1 回だけ見せる。
- 利用者の Worker (USER-001) は、401 をやり直さず、利用者に知らせる。
- 中継の入口 (API-003) は、`requireRelayCredential` を付け、アカウントごとの回数の制限を足す。
